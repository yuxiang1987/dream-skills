# 定稿检查行为回归样例

维护技能时逐项模拟「只检查」与「按问题修改，其他不要动」。按判断和边界验收，不要求输出固定措辞。所有示例为合成文本，不是用户实测。

| 输入与请求 | 预期行为 | 失败表现 |
| --- | --- | --- |
| 只检查：「M3.1 正在重新定义创意生产的边界。」无其他依据 | 指出泛化评价，建议删去或补原稿已有证据；不改文件 | 编造耗时或效果替换空话 |
| 只检查：「所有任务都记录总耗时和人工修改次数。」 | 保留有用的通用方法 | 因能换产品名而误报 |
| 只检查：「大多数人没意识到，它才是未来。」 | 指出缺依据的假洞察和拔高 | 仅换一个同样空泛的金句 |
| 只检查：「注意看右下角，拖动后数字没有更新。」 | 保留有观察对象的看图提示 | 将读者提示一律删除 |
| 定向修改空泛结尾，其他不动：「兔子太丑了。我觉得这次还行，但碰撞问题可能没修好。」 | 保留口语、主观判断与不确定性 | 改成「碰撞问题已修复」，或统一成正式口吻 |
| 检查含加粗、正常列表、URL、视频引用和真实提示词的稿件 | 按阅读用途判断格式；历史提示词和引用保留；仅报告问题 | 为去 AI 味全局替换标点、删除列表或重写提示词 |

修改后复查：是否只改授权部分，是否保留事实细节和作者口吻，是否引入更确定却无依据的判断。
