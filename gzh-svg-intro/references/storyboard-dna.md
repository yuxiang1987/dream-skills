# 公众号 SVG+SMIL 片头分镜与物理反馈规范

本规范蒸馏自摸鱼小李近期 25 篇公众号纯 SVG+SMIL 片头与「程序员梦哥」已验证样片（含无卡节点管道、3D 透视视口、单视口分栏改写、调校舱插卡及四案例连弹）。

## 一、画布与技术硬约束（保证微信富文本粘贴兼容）

1. **统一画布**：`width="1246" height="220" viewBox="0 0 1246 220" preserveAspectRatio="xMidYMid meet"`，最外层 `style="display:block;width:100%;height:auto;max-width:1246px;margin:0 auto;background:transparent;"`。
2. **纯矢量声明式动画（零外部依赖）**：
   - 只使用 `<svg>`、`<g>`、`<path>`、`<rect>`、`<circle>`、`<ellipse>`、`<line>`、`<animate>`、`<animateTransform>`。
   - **严禁出现** `<text>`、`<image>`、`<script>`、`<foreignObject>`、`<defs>`、`<style>` 或外部字体/图片引用。
   - 所有中英文文字必须通过 `scripts/build_svg_intro.py` 中的 `FontEngine`（纯 Python TrueType 轮廓提取器）预先转换为闭合 `<path>`。
3. **纯透明/白底舞台，拒绝整幅外框**：
   - 不要用一整张浅蓝或深色大卡片把整个 1246×220 画布框起来（避免像网页后台仪表盘）。
   - 保持背景透明，只绘制左侧像素梦哥、点阵口号与右侧故事道具。

## 二、8 秒循环标准时间轴与双周期节奏

| 时间区间 | `keyTimes` (8s) | 阶段 | 画面动作 |
| --- | --- | --- | --- |
| `0.00s – 1.20s` | `0.00 – 0.15` | 品牌亮相 | 左侧像素梦哥待机（`2.2s` 呼吸微摆 + `3.2s` 眨眼，与 8s 主周期异步错开）；右侧展示带 0.5px 网格缝隙的大号点阵字「**程序员梦哥，分享AI少踩坑**」（前半灰蓝 `#8291A5`，后半品牌蓝 `#1E6FFF`） |
| `1.20s – 1.92s` | `0.15 – 0.24` | 粒子坍缩 | 16 个点阵切片以 `keySplines=".77 0 .175 1"` 同时缩小（`1 -> 0.74 -> 0.16`）、淡出，并交接为 10×10 灰蓝/亮蓝方块粒子飞入舞台中央 |
| `1.76s – 7.04s` | `0.22 – 0.88` | 主题舞台 | 主舞台在 `0.22–0.26` 淡入，依次演绎 2–4 个有因果反馈的动作节拍，在 `0.78–0.85` 弹出完成绿勾与点睛气泡 |
| `7.04s – 8.00s` | `0.88 – 1.00` | 粒子复位 | 主舞台淡出，16 组点阵字从舞台回流放大复位，无缝进入下一轮 8 秒循环 |

## 从正文动作构思分镜

以 WorkBuddy 健身小程序教程为例。正文里最有辨识度的变化是：作者提出需求，比较三套原型，选中炭黑青柠的方案 C，最后在手机试用版点下“开始运动”。围绕“挑选、成形、启动”，同一篇文章可以有三种演法。

| 构想 | 道具、构图与连续动作 | 专门绘制的部件 |
| --- | --- | --- |
| 折纸手机 | 三张纸在画面中央展开，选中的 C 稿沿折痕收拢成手机。指尖压下按钮，原稿上的圆环随屏幕亮起。 | 可翻折的侧翼和顶角、贯穿两幕的能量环、指尖 |
| 小程序施工台 | 工单滑上横向工位，机械臂按选中的样稿把能量环和按钮装进机身。按钮落座回弹，手机滑到手边供试用。 | 夹爪、可装配的屏幕零件、滑轨 |
| 运动接力 | 镜头跟着接力棒横穿跑道。需求纸卷成棒，下一棒展开露出选中的青柠设计，终点的手机接棒后启动计时。 | 能卷起和展开的纸棒、交接的手、终点手机 |

这个案例优先选折纸，因为同一只青柠环能从设计稿一直保留到可点击的手机上，缩小画面仍能看出“原型成了能用的东西”。换成一篇多模型协作文章，先重新找它独有的变化。例如只有当几项工作确实同时进行、最后汇合时，章鱼的多条触手才有各自动手的理由。

## 三、从标题和正文取材的四条法则

1. **标题定主角与态度，正文给具体节拍和真实数字**：
   - 不要只把文章标题抄进片头。必须通读正文，提取作者**真正做过的 2–4 个具体案例、设置项或实测数据**（如 WorkBuddy 篇的「C盘迁D盘 / 4条编码准则+高效务实 / 长期记忆+大黄」；Kimi K3.1 Pro 篇的「布料模拟 / 云海古城 3D / 卡丁车 3 圈竞速 / `world.execute(me)` 代码 MV + 5 小时用量 `76.29%` 肉疼」）。
2. **找一个贴合题材的核心道具隐喻（Visual Metaphor），避免“全员卡片化”**：
   - **按已选分镜落地**：需要多卡切换时可复用卡带动作，需要物体连续变形时可自绘部件，在 `x=260..1180` 的主题舞台上展开。以下是现成实现可承担的动作。
   - **节点连线管道（`pipeline-nodes`，无卡片）**：左侧光源发出一颗光点，沿虚线贝塞尔路径依次跳亮 3 个圆形里程碑节点（每颗节点用 `scale_around` 过冲点亮），最后落到右侧目标端弹出绿勾。
   - **3D 透视视口 + 2.5D 图层炸开（`viewport-3d`，无卡片堆叠）**：左侧用 `smil_stroke_draw` 生长取景框与 XYZ 坐标轴、铺开 `perspective_grid` 透视地面网格，再用 `smil_attr("points", ...)` 驱动三维着色立方体透视旋转；右侧用 `skew_around("skewY", ...)` 将 3 层玻璃图层横向炸开再吸合。
   - **单视口分栏工作台（`split-editor`，无多卡飞出）**：左侧文件图标右键触发，右侧展开单张左右分栏工作台，左栏文本行用 `smil_attr("width" / "fill", ...)` 就地改写高亮，右栏对话指令与进度条同步完成。
   - **设置/多模型/工具流题材（`console-3act`）**：调校舱插卡槽 + 右侧伙伴机器人 + 7 格进度灯柱，待命卡位于右上侧、已用卡弹到左侧堆叠。
   - **多案例实测/横评/作品集题材（`showcase-4card`）**：左侧标志性发射主机连续蓄力抛出 3–4 张带卡内持续微动效的微缩作品卡，右侧放实测结论与槽点仪表。
   - **主循环时长自适应**：简单单幕可用 `5s`–`5.5s`，中等叙事用 `6s`，复杂三幕用 `8s`；左侧像素梦哥呼吸（`2.2s`）与眨眼（`3.2s`）始终保持异步微循环。
3. **丝滑感来自「物理因果反馈 + 线稿生长 + 黄金缓动分工」，而非堆砌无关特效**：
   - **四大黄金缓动曲线分工（`calcMode="spline"`）**：
     - `0.23 1 0.32 1`：弹出、落地、过冲回弹（最常用，如节点点亮、绿勾弹出、粒子喷出）；
     - `0.45 0 0.55 1`：呼吸、悬浮、平滑状态过渡；
     - `0.55 0 0.85 0.45`：火箭/弹丸加速冲刺离场；
     - `0 0 1 1`：高频线性抖动、火焰闪烁、机械节拍。
   - **三段式物理发射（`launch_recoil`）**：点火前先 `1.6px` 高频微震，起飞前先向后退 `26px` 并轴向挤压（`scale=".94 1.07"`）蓄力，再拉伸（`1.1 .93`）加速冲出画布。
   - **线稿画入与反向擦除（`smil_stroke_draw`）**：支持前半程 `length -> 0` 画出坐标轴/星图/路径，后半程 `0 -> -length` 擦除退场，实现“旧隐喻→新隐喻”无痕转场。
   - **抛物线粒子喷泉与波浪队列（`particle_fountain` / `stagger_bounce`）**：多粒音符/火花按 `0.015` 错峰抛物线飘出铺满横幅；多角色/图标落地后按 `0.025` 错峰轻跳。
   - **旋转与 2.5D 透视**：用 `rotate_around` 驱动机械臂/天体/道具摆动，用 `skew_around("skewY", ...)` 实现图层轴测炸开，用 `smil_attr("points", ...)` 实现 3D 多面体投影旋转。
   - **碰撞回弹与卡内微动效**：落槽/发射带机身下沉回弹、闪光与火花；展示卡内保持持续微动效（布料、云海、赛车、频谱）。
4. **严查遮挡与证据边界**：
   - 生成 SVG 后检查待命卡、堆叠卡、频谱柱、印章绿勾是否压住任何文字。
   - 只把正文中作者真正实测或明确写出的数据放进片头，不虚构未测功能、价格或跑分结论。
   - `aria-label` 按统一分镜句式书写：`程序员梦哥，分享AI少踩坑；像素文字变成粒子；[主道具与 2-4 个动作节拍描述]，最后弹出对勾与[收尾结论]`。
