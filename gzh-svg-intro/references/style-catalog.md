# 多流派视觉风格灵感库（GSAP Showcase × 摸鱼小李）

为了彻底摆脱“每篇都是卡片”或“每篇都是线条串珠”的单一套路，创作新片头前，先从下面 **2 大源流（共 12 种视觉流派）** 中为文章挑选 **2–3 个不同流派的分镜方向**，由用户拍板后再定制绘制。

---

## 一、GSAP Showcase 五大移植流派（强排版、强图形张力）

1. **瑞士网格 + 动态排版流（参考 *FORMAT* / *TTM* / *niceunderground*）**
   - **视觉特征**：高对比单色/黑白底 + 一抹亮色点缀，极简网格线切分，粗大标题关键词本身就是主角。
   - **微信 SVG+SMIL 技法**：`FontEngine.chars(...)` + `split_text_stagger(..., mode="pop"|"rise"|"wave")` 逐字错峰弹出或波浪跳动，搭配 `smil_stroke_draw` 网格线切分。
   - **适用题材**：观点文、行业发布解读、方法论总结、金句强主张文章。

2. **涂鸦手绘 + 刻度盘 + 液态变形流（参考 *NiceCrate* / *Umoh Samuel*）**
   - **视觉特征**：手绘线条生长、圆形刻度盘/仪表指针转动、核心图标或几何体直接液态变形（`MorphSVG`）。
   - **微信 SVG+SMIL 技法**：`morph_d(...)`（Python 预对齐锚点做 `d` 变形）+ `smil_stroke_draw` 手绘生长 + `rotate_around` 刻度盘。
   - **适用题材**：设计工具、灵感创作、能力进化对比（如旧版→新版形态跃迁）。

3. **暗调产品 UI + 2.5D 倾斜浮卡流（参考 *Autopilot* / *Butter* / *Nuvora*）**
   - **视觉特征**：深色高对比界面层，用 2.5D 斜切透视浮层展示产品核心界面与实时数据变化。
   - **微信 SVG+SMIL 技法**：`skew_around("skewY", ...)` + `smil_attr("width"|"fill", ...)` 数据跳动 + `bounce_drop` 弹性落位。
   - **适用题材**：SaaS 工具评测、Dashboard/工作台类产品、效率插件。

4. **复古电视 / 立体微缩布景流（参考 *Better Call Quang* / *The Two way portfolio*）**
   - **视觉特征**：复古 CRT 电视、户外路牌、物理沙盒/工作台等有触感的微缩道具场景。
   - **微信 SVG+SMIL 技法**：纯矢量实体道具 + `launch_recoil` 碰撞回弹 + `particle_fountain` 物理粒子。
   - **适用题材**：游戏开发、3D 建模、硬核实测、多项目挑战。

5. **数字笔记 / 知识图谱流（参考 *AI Ui(s)*）**
   - **视觉特征**：蓝白/米白笔记本网格、手写感连线与节点展开。
   - **微信 SVG+SMIL 技法**：`smil_stroke_draw` 连线 + `ripple_pulse` 节点波纹 + 局部高亮批注。
   - **适用题材**：知识库、长文拆解、Prompt 教程、学习路线。

## 二、摸鱼小李七大空间构图范式

1. **隐喻变形流**：双道具物理变形与跨画布转场（望远镜→星空→听诊器；几何草图→火箭发射）。
2. **2.5D/3D 空间炸开**：`perspective_grid` 透视网格 + `animate:points` 旋转立方体 + `skewY` 多层玻璃炸开吸合。
3. **角色表演 + 全幅粒子**：左侧角色随节拍动作，音符/火花/星尘铺满整条横幅。
4. **单视口内切幕**：固定一台监视器或画布，内部切换三幕内容或局部选框三连改。
5. **左右分屏编辑器**：左栏文档/代码行就地改写高亮，右栏对话指令同步完成。
6. **节点连线管道**：仅用于纯 Agent 工作流/自动化流水线，光点沿贝塞尔路径依次点亮里程碑。
7. **机台插卡 / 连弹作品卡**：仅用于参数切换（`console-3act`）或多案例横评（`showcase-4card`）。

## 三、“一文一景”创作铁律

- **不默认套模板**：5 套内置 CLI 模板只用于快速草稿或回归基线；正式出稿优先结合上述流派为每篇文章单独构图。
- **同批不撞型**：严禁连续两篇使用同一种空间骨架（如连续用卡片或连续用虚线串珠）。
- **物理与节奏**：优先用 `bounce_drop`（多段衰减落地）、`launch_recoil`（后坐发射）、`morph_d`（平滑变形）替代生硬的淡入淡出。
