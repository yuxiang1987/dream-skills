# 公众号 SVG 片头动画回归核对用例

以下场景用于核对 `gzh-svg-intro` 的分镜取材、证据边界与微信内嵌 SVG 合规要求：

## 用例 1：设置与工具调优教程（《WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你》）

- **输入材料**：正文讲解 7 处设置（默认存储路径从 C 盘改到 1TB D 盘、4 条编码自定义指令、高效务实回复风格 + 互相称呼大黄/boss、人设与长期记忆、记忆与进化沉淀 Skill、窗口模型与台账省 Token、数据导入）。
- **期望分镜**：
  1. `0.0s – 1.92s` 左侧像素梦哥待机，右侧点阵字「程序员梦哥，分享AI少踩坑」在 1.2s 后 16 组同步坍缩为粒子。
  2. 主舞台采用「调校舱插卡 + 机器人大黄 + 7 格设置灯柱」，把 7 处设置凝练成 3 张飞入顶部卡槽的模块卡（`存储路径·D盘`、`指令·风格·务实`、`长期记忆·7/7`）。
  3. 待命卡位于调校舱右上侧，已用卡弹到左侧堆叠，插槽卡面文字完整露出，不遮挡机身和屏幕。
  4. 每次落槽带机身下沉回弹、闪光、脉冲发射与大黄挤压下蹲；满格后弹出绿勾与「Boss，越用越懂你！」。

## 用例 2：多案例模型实测（《实测 Kimi K3.1 Pro，国模一哥，有惊喜也有槽点！》）

- **输入材料**：3 万亿参数、100 万上下文；4 个实测案例（Three.js 布料模拟器 + KIMI 复古电脑屏幕 `K3.1 PRO` 闪动不糊且阴影同步、4 图参考 Blender 云海浮岛古城与北缘巨像、3 圈 5 对手漂移氮气卡丁车、`world.execute(me)` 红白几何纯代码 MV）；槽点是做完第一个项目 5 小时用量就到了 `76.29%` 肉疼。
- **期望分镜**：
  1. 主舞台左侧还原文中 `KI [复古 CRT 电脑] MI` 主机，屏幕亮起蓝青色 `K3.1 PRO` 扫描线文字。
  2. 电脑连续 4 次蓄力回弹，呈抛物线弹出 4 张作品卡；每张卡内都有对应的持续微动效（布料与阴影摇晃、云海浮动、卡丁车喷氮气绕圈、MV 频谱跳动且不压底部歌名），逐一弹出完成绿勾。
  3. 右侧弹出「惊喜：4案全通 / 槽点：额度肉疼」面板，`5 小时用量 (Kimi Code)` 进度条从蓝色飙升到橙红色 `76.29%`，亮出「1个项目干掉 76% 额度 · 肝疼!」。

## 用例 3：非卡片舞台模板（`pipeline-nodes` / `viewport-3d` / `split-editor`）

- **输入材料**：Agent 自动化流程、3D 模型空间能力实测、本地文件 AI 就地改写。
- **期望分镜**：
  1. `pipeline-nodes`：无矩形卡片框，左侧光源发出光点沿贝塞尔虚线依次点亮 3 个圆形节点，抵达右侧目标端并弹出对勾。
  2. `viewport-3d`：3D 取景框、透视地面网格与 XYZ 坐标轴通过 `stroke-dashoffset` 动态生长，三维立方体以 `animate:points` 旋转，右侧 3 层 `skewY` 图层炸开再吸合。
  3. `split-editor`：单视口分栏工作台内左栏文档行通过 `width`/`fill` 动画就地改写高亮，不向外弹出多张卡片。

## 用例 4：微信 SVG 合规与证据边界

- **结构合规**：生成的 `.svg` 必须包含 `viewBox="0 0 1246 220"` 与 `calcMode="spline"`，且零 `<text>`、零 `<image>`、零 `<script>`、零 `<defs>`、零 `<style>`、零 `<foreignObject>`。
- **证据边界**：不得把文章未实测的功能、未出现的跑分或虚构的省钱比例写进片头；本地预览页通过不等于微信真机已验收。

## 用例 5：同篇发散、选案与制作范围

输入健身小程序教程，材料包括三套原型、选中青柠方案 C、手机试用版可开始运动。

- “先给三个片头创意，我选好再做”：交付三个有不同主角、构图和动作因果的故事，并说明推荐理由。验收时遮住字幕，若三案都是三张卡依次飞入，只改标题、颜色或贴图，则重新构思。此轮交付到分镜。
- “直接做一版”：从候选中选一个并生成 SVG 和预览页。抽查动作触发前后两帧，按下“开始运动”后才出现运动反馈，结尾对应手机试用。
- “就做折纸手机，主角换成我的像素人物”：从指定故事继续拆纸翼、折痕和按钮，无需重开选案。换一个题材再试，例如多模型协作，观察每个道具的动作能否对应新正文里的任务。
