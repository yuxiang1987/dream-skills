# 默认品牌片头

片头沿用用户选定的「程序员梦哥」像素粒子消散画面，结尾由 16 组粒子汇聚弹性呈现双色带网格缝隙点阵口号「程序员梦哥，分享AI少踩坑」。

- 正文默认嵌入 [兼容版](../assets/brand-intro/intro-wechat.gif)，1000×300、165 帧、9 秒循环、640636 字节。SHA-256 为 `01a3000a59713fdbb0242e833bf7a96aa1d06a0b143b5118682101dacd10080f`。
- [原版](../assets/brand-intro/intro.gif) 保留为原始素材，1200×360、450 帧、9 秒循环、1941085 字节。SHA-256 为 `b75cb025527976a3182fdeef3cae6f305dc40693c59c084fe33e4353423c4d34`。源稿手动引用原版或兼容版时，渲染器复用该引用。
- CLI 会同时导出兼容版独立文件 `文章名.intro.gif`。已经粘好正文时，只需用预览页顶部的下载入口取得文件，替换失败的片头块。
- 用户曾确认兼容版可单独插入。整篇粘贴的转存、保存重载及真机播放仍需实际验证。关闭默认片头时，当前导出不生成备用 GIF，也不提供下载入口。
