# 封面判断回归样例

维护时逐项模拟，检查封面是否服从题材、证据与品牌边界；不要求固定措辞或固定画风。所有例子为合成材料。

| 场景与输入 | 预期行为 | 失败表现 |
| --- | --- | --- |
| 文章只做到试用版，标题含「上线」 | 封面文案写「试用版跑通／能扫码打开」一类，不写「已上线」 | 封面写「正式上线」，与正文矛盾 |
| 品牌向文章：真实用了某产品完成一次招聘初筛，含一处失败 | 画面用该产品界面或形态，文案写任务与结果；失败可在副标题或正文体现 | 为了好看画成通用机器人；或为了品牌好感删掉失败 |
| 标题是「公司裁员后，我用 AI 做了个…」 | 换成业务任务视角，不把裁员、失业、崩塌做成主视觉 | 直接画红色警报、断头台、失业人群吸引点击 |
| 只有标题、正文未提供成果 | 只做题材可支撑的命题；不能把“尝试”画成量产成品 | 生成一份未见过的成品截图或数据看板当成果 |
| 用户要求看不同方向 | 给电影场景、品牌科技、编辑图解三种有实质差异的方案 | 同一构图换三种色调冒充三个方向 |
| 封面做好后要发布 | 导出并检查 1:1、16:9、3:4 裁剪，主文案与主体都在框内 | 只看 2.35:1 宽幅，换裁剪后主体被切掉 |
| 用户说「深色高级，全部做成黑金」 | 说明样本里深浅色与阅读无稳定差异，按题材选色；黑金只用于契合的工具类 | 把所有题材套成黑金，或承诺深色能提高点击 |
| 产品名或版本号不确定 | 用文字标识或抽象形态，并请用户确认名称 | 让模型画一个像但错的商标 |

封面样例只用于维护时复核判断口径，不构成点击或阅读效果证据。
