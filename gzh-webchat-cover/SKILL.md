# 路人甲式公众号封面

先读 [references/style-dna.md](references/style-dna.md)。需要核对蒸馏依据时，再读 [references/sample-map.md](references/sample-map.md) 并查看 `assets/reference-covers/`。

## 目标

把文章标题转成一张“先看懂讲什么，再感到值得点开”的横版封面。学习样本的编辑决策，不逐像素仿制任何单张作品，也不要把所有选题硬套成同一种画风。

默认交付：

- 一张 `900 × 383` PNG，比例约 `2.35:1`；关键内容避开四周 5% 安全区。
- 一句封面主标题，必要时增加一句短副标题。
- 一份简短设计说明：标题如何压缩、为何选该画面、使用了哪些素材或工具。

## 工作流

1. 读取用户给出的文章标题、摘要或正文。若只有标题且不影响主视觉判断，直接完成；若核心交付物不清楚，先从正文找“作者实际做了什么”。
2. 把原标题拆成：对象、作者动作、可见成果、读者问题、情绪。只选其中一个作为画面命题。
3. 将长标题压成 6–18 个汉字或“产品名＋短判断”。封面文案与文章标题互补，不照抄整句。
4. 按 `style-dna.md` 选择一种画面模式。先确定主体、左右布局、光线与色彩，再生成背景。
5. 生成背景时不要让模型绘制中文文字。优先使用 `imagegen` 生成无字背景；用户提供产品截图、作品图或人物素材时，在其授权范围内优先使用真实素材。
6. 使用 `scripts/compose_cover.py` 叠加清晰中文文字。主标题最多两行，每行尽量不超过 12 个汉字；只突出一个关键词。
7. 在缩略图尺度检查：3 秒内是否能看懂对象和动作；文字是否清楚；主体是否被裁切；封面是否重复了文章标题却没有增加信息。

## 选择画面模式

- **作品复刻／AI 视频／创作成果**：用成片级场景占满画面，人物或作品主体放右侧，左侧写“对象＋动作”。
- **产品实测／Coding／Agent**：产品标识和一句结论在左，抽象能力或界面装置在右；黑金、深蓝或品牌色优先。
- **功能突破／前后对比**：直接把“变化”做成画面，例如草图变成成品、旧形态变新形态；不要用泛化机器人代替功能。
- **教程**：用平静、易进入的场景或清爽界面；标题强调“最新教程／从零上手／完成什么”，降低视觉攻击性。
- **行业观察／宏大判断**：用单一象征场景承载命题，例如窗外地球、远山日出、人与机器相遇；文字更少，留出沉思空间。
- **模型机制／参数解释**：使用浅色编辑图解、几何结构和高对比黑字，避免电影场景抢走解释任务。

## 质量边界

- 不虚构文章没有完成的成果，不把“尝试”画成“已经量产”。
- 不把商标、产品 UI 或人物肖像画错；无法确认时使用文字标识或抽象形态。
- 不把参考样本中的阅读量、日期、头像和微信列表界面做进封面。
- 不堆满产品名、标题、卖点、标签和装饰。一个封面只保留一个视觉主语和一个阅读动作。
- 不默认使用赛博朋克、机器人、代码雨或蓝紫渐变；它们只有在标题语义需要时才出现。
- 生成完成后展示成品并给出保存路径。若用户要求多个方向，优先提供“电影场景、品牌科技、编辑图解”三种有实质差异的方案。

## 排字工具

```powershell
python scripts/compose_cover.py --background <背景图> --output <输出.png> --title "主标题" --subtitle "副标题" --accent "#F2C94C"
```

工具会裁切到 900×383、增加左侧可读性渐变，并寻找常见中文字体。背景本身已留出暗区时，可用 `--overlay 0.15` 降低遮罩强度。
