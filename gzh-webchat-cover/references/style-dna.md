# 封面风格 DNA

## 核心判断

样本没有统一画风，统一的是标题到画面的编辑关系：**文章标题讲完整故事，封面把故事压成一个可以被看见的命题。**

## 稳定特征

1. **宽银幕构图**：约 2.35:1，像电影横幅。常见布局是左文右物，也允许左侧主体、右侧留景深。
2. **一个主语**：封面围绕一个人物、产品装置、作品场景或几何概念展开。辅助物只负责说明主语。
3. **短文案**：通常一到两行，保留产品名、动作或结论；不复制完整文章标题。
4. **题材决定画风**：作品类用电影剧照，技术产品用品牌化科技视觉，机制解释用编辑图解，生活观察用风景和人物。
5. **克制的强调色**：文字以白色或黑色为主，只让一个词使用金黄、青绿、红线或品牌色。
6. **光线参与叙事**：暖色日落对应完成、出发和人的故事；黑金对应成熟工具和效率；深蓝星空对应未来判断；米白纸张对应解释与测评。
7. **封面与标题分工**：封面先交代“看点是什么”，列表标题再补充投入、结果、情绪和悬念。

## 标题压缩规则

按优先级保留：

1. 能被画出来的成果或变化。
2. 产品／模型名。
3. 作者动作。
4. 一句克制判断。

优先删除发布时间、投入时长、热度数字、夸张副词和解释性从句，除非它们就是文章的核心证据。

| 文章标题结构 | 封面转译 |
| --- | --- |
| 热点名场面＋我用工具尝试复刻 | IP/作品场景＋“我用 X 做了一版自己的” |
| 我手搓了一套产品配件 | 工作台上的整套成品＋“给 X 手搓一套配件” |
| 新功能真的变强了 | 前后形态同框＋“产品实测／功能可以给到…” |
| 为了完成长任务，我做了个 Skill | 电影场景＋“长视频一镜到底 Skill” |
| 模型开放＋连测＋宏大问题 | 宇宙或未来场景＋“产品实测来了” |
| 参数／机制实测 | 浅色几何图解＋“对象实测／参数拉满，交付顶级” |

## 构图参数

- 画布：900×383。
- 文案区：左侧约 38%–48%，上下居中或略偏上。
- 主体区：右侧约 45%–60%，主体视线或运动方向朝向画面内部。
- 主标题：两行以内，占画布高度约 14%–22%。
- 副标题：主标题字号的 35%–50%，透明度略低。
- 画面边缘避免重要五官、Logo 和标题；微信卡片会缩放并可能轻微裁切。

## 五种配色

| 情绪 | 背景 | 主文字 | 强调色 |
| --- | --- | --- | --- |
| 工具成熟、Coding、效率 | 黑／炭灰 | 白 | 金黄 |
| 模型突破、未来判断 | 深蓝／星空黑 | 白 | 冰蓝 |
| 创作、电影、实战作品 | 场景原色 | 白 | 与主光源同色 |
| 人的故事、生活变化 | 日出暖金／自然蓝绿 | 白 | 暖黄 |
| 原理、参数、教程解释 | 米白／浅灰 | 黑 | 单点青绿或浅黄 |

## 字体语气

- 默认使用粗黑体表达实测、动作和结论。
- 只有浪漫、旅行、思考或教程的画面适合中等字重宋体／衬线体。
- 产品英文名保持官方大小写；中英文之间保留自然间距。
- 不使用三种以上字体，不给所有字描边，不用夸张 3D 字效。

## 失败信号

- 画面只是通用 AI 机器人，换任何标题都成立。
- 标题全文塞进封面，缩略图无法读完。
- 主体、Logo、标题都在抢第一视觉。
- 画面宣称的完成度高于正文证据。
- 每篇都黑金、蓝紫或电影海报，失去题材差异。
