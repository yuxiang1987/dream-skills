# 样本映射与证据边界

本指南来自用户提供的 12 张路人甲TM公众号列表截图，以及知识库 `wiki/topics/文章标题库.md` 中已拆解的标题。截图只覆盖一部分文章，不能推出账号全部历史封面的统计规律。

| 样本 | 标题与封面的关系 | 可迁移判断 |
| --- | --- | --- |
| 《凡人修仙传》名场面／Pixmax | 正文标题讲热点与尝试，封面直接展示仙侠结婴场景；文字交代“用 Pixmax 做自己的版本” | 作品类先让读者看见作品，再说明工具 |
| iPhone Duo 配件 | 长标题的调侃被删掉，封面改成工作台上的整套配件 | 成果集合比情绪梗更适合作为封面主体 |
| GPT Image2.5 草图生图 | 蝴蝶从线稿变成蓝色成品，红铅笔强化“草图” | 功能升级应被画成变化，不要只放模型 Logo |
| 长视频 Skill | 西部片人物与夕阳提供“大片”感，封面文案压成工具名与结果 | 自建工具题材用目标世界呈现价值 |
| 豆包生活故事 | 人与狗看日出，封面只写“豆包工作，你变了” | 人情味选题适合少字、风景和留白 |
| GPT-6 Astra 实测 | 星系形成数字 6，左侧只写“实测来了” | 首发实测可用产品符号化视觉，不必列测试项 |
| GPT-6 Astra 演示汇总 | 人坐在地球前，中心突出 2026，左侧给产品与疑问 | 宏大判断用象征场景，标题负责补足信息性质 |
| Seed-Evolving | 官方 Logo＋浅色抽象曲面＋“持续升级” | 有成熟品牌资产时保持品牌语言，不强行电影化 |
| AI 自媒体链路 | 机器人向人递玫瑰，城市背景承载传播规模 | 行业事件用一个可理解的隐喻串起抽象链路 |
| Qoder | 黑金产品界面阵列，左侧 Logo 与一句判断 | Coding 产品用界面能力和秩序感，少用人形机器人 |
| Hy4 preview | 米白纸面、几何图和大号变量 | 参数解释适合编辑图解，清晰度优先于氛围 |
| WorkBuddy 教程 | 湖面孤树与山景，只有教程名 | 入门教程可降低刺激，用平静画面传达易进入感 |

## 不能据此断言的内容

- 这些截图未说明封面由作者、品牌方还是生成工具制作。
- 不能仅凭 12 张图断言固定字体、固定色值或固定生成模型。
- 样本中既有摄影感、电影感、品牌 KV 和编辑图解，因此“统一画风”不是事实；统一的是信息组织。
