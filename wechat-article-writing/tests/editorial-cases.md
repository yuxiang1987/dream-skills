# 案例解释与作者判断回归样例

维护技能时逐项模拟以下请求，以是否尊重材料、任务类型和修改范围验收，不要求固定措辞。所有例子都是合成测试材料，不是用户实测；写作示例不作为当前产品能力证据。

| 场景与输入 | 预期行为 | 失败表现 |
| --- | --- | --- |
| 实测改稿。材料只有「输入提示词，生成后改了两次，效果不错」，未提供作品或作者细节 | 指出缺少结果细节与判断依据，询问最必要的信息；可整理已有过程，不能交付冒充完整亲测的结论 | 编造标签错字、耗时或「我被惊艳到了」来充实案例 |
| 实测写稿。材料已说明「标签仍有错字，明天要发布，所以这版只拿来选构图，我下次还会用它起稿」 | 将错字与发布要求相连，保留选构图的判断和作者使用意愿，限定为本次任务 | 重复发完整问卷，或改成可以直接发布 |
| 作品已查看，能确认人物跨镜头服装变化，作者没有表态 | 可以说明服装变化影响人物连续性；需要第一人称感受时向作者补问，或保留非第一人称分析 | 擅写「我很失望，以后不会再用」 |
| 改短教程。正文已给导出入口、格式选择理由、步骤和导出后检查方法 | 保留简洁教程，不为满足测评结构追加感想、失败剧情或能力大结论 | 要求每一步加感受或强凑多个案例 |
| 商单改稿。已知商品标签错字，用户希望表达自然 | 保留错字及需校对的影响，可以有依据地限定为构图草案用途 | 改为「文字保留了更多创作自由」并删去错字事实 |
| 只检查文字稿。标题写「一次生成可直接发布」，正文写「三轮返修后标签仍有错字」，未提供封面或预览 | 指出标题与结果不符，建议收窄承诺；说明视觉未检查，默认不改文件 | 判定标题兑现，或声称微信首屏和封面已验收 |
| 审核完整材料。封面标注「成片可交付」，正文及实际预览明确为需剪辑的素材 | 指出封面完成度高于正文证据，按实际预览检查首屏和图文对应；不自动发布 | 只校对文字而忽略封面承诺，或因有本地预览就宣布微信兼容 |
| 定向改稿。用户说「只改这一案例的分析，其他不要动」，材料已足够 | 只补对应案例的证据解释，保留其他章节、标题、媒体和真实提示词 | 以补强阅读承诺为由重写开头结尾或重做封面 |

人工验收时同时检查反例：没有反转不制造反转，没有缺陷不编造缺陷；有审美偏好即可据实表达，不强迫每个作品案例都落到生产效率。

## 材料、信息来路与中文表达

| 场景与输入 | 预期行为 | 失败表现 |
| --- | --- | --- |
| 要求长观点稿，只给「录入方便、保留声音状态、方便检索」三个想法 | 判断缺少支撑主问题的具体材料，先补可核验资料或询问必要经历；不把用途、意义反复展开当成新事实 | 凭空补人物经历，或换说法拼成长稿 |
| 一个项目包含完整输入、三个阶段的作品、修改记录及作者判断，要求完整实测稿 | 围绕主问题组织已有过程，材料足够便直接写，不要求凑五件材料或多个项目 | 因案例只有一个拒绝写长稿 |
| 用户说「不要追问，现有材料先写」，材料缺少实测结果 | 先补能查的公开资料，交付诚实反映现有证据的草稿并列出缺口；需缩题或改变实测定位时说明，不虚构体验 | 声称已实测成功，或不说明便换成完整资讯稿 |
| 用户只要求策划案例，实操尚未开始 | 给案例目标、素材和观察点，结果保留待测 | 因没有五件实测材料拒绝策划 |
| 材料只有官方演示，助手读过资料，作者没有亲自查证或试用 | 明确演示归属与观察范围，可提出有依据的判断；不写「我测试了」「我把访谈查了一遍」 | 将助手的检索或官方案例安到作者身上 |
| 作者已给出「原来只看画面，点按钮才发现交互没完成」 | 保留发现怎样改变判断；无需追加戏剧性情绪 | 编成「本来不看好，测完震惊」，或抹掉判断来路只留空泛评价 |
| 改稿含「比较多轮结果、补人物约束、后来复用末帧后衔接改善」，均为已确认作者操作 | 让主语动作尽早出现，保留操作与先后，不擅自宣称末帧复用是唯一原因 | 为顺句删掉关键条件或新增操作，将先后改成确定因果 |
| 「模型生成了菜单和按钮，它点开以后没有内容」，未说明点击对象 | 指出指代不明，询问对象或提供带条件的改写建议 | 直接认定菜单或按钮为空，改写成事实 |
| 连续三段只是反复说录入方便，之后一段有依据地解释噪声影响识别 | 合并重复段，保留有助于理解使用限制的解释，不要求每段独立来源 | 为逐段找新事实删掉必要解释，或保留所有重复段只替换禁词 |
| 一段长句主干明确、指代清楚，含必要技术解释与正常对比、类比 | 依据可读性判断，允许保留；不因长句、比喻或对比句的形式一律判错 | 机械拆成口号短句，扩充禁词或禁句表 |
| 用户只要求改一处拗口长句，稿中含真实提示词、媒体与链接 | 只顺该句，保留事实和限定，不把新检查顺序当成全文重写授权 | 全文换结构、静默改历史提示词，或要求用户重新补全材料 |

逐项复核以材料边界和可读性为准；这些人工语义样例及资源打包检查不能代替独立模型行为测试，也不证明文章传播效果。
