# 六维拆解口径

先确定目标读者、核心问题、题材与信息身份，再拆写法。资讯可以按事件与信息层级，教程按前提—步骤—验收，观点按问题—论据—解释组织；不把所有文章强套多案例测评。维度回答「怎么写」，不是给作者打分。每条关键判断展开为：**观察 → 原文定位依据 → 解释 → 适用条件 → 自己的待测方向**。

## 一、标题与开头

记录标题承诺的对象、动作、数量、收益和情绪；找正文对应兑现位置。记录开头用结果、痛点、事件或疑问怎样引入读者问题。标题与正文有距离就具体说明，不直接贴「标题党」标签。语言节奏看句长、设问、口语、停顿如何服务阅读，不复制口号与人设。

## 二、结构推进

记段落与转场是任务接续、难度增加、问题修复、复用延伸还是并列铺开；多案例要说明各观察什么，是否服务同一问题。图文作用只依据实际看过的材料：图是在展示结果、解释步骤还是作比较；未看的部分只记录存在与未核范围。标题步骤数与小节数不同，先区分主流程和附赠内容。

## 三、案例、解释与观察

逐例记录真实目标、输入、关键操作、结果、人工修正、耗时与成本口径；未给的信息写未提供，不补编。耗时区分首次学习、单次生成、重试和人工处理，费用区分积分、订阅、外部工具和总成本，不能用单次报价代替完整成本。

解释与观点记清「原文观察支持什么」「作者如何归因」「尚缺什么证据」。把结构组织方法与产品能力结论分开：能学同素材对照，不代表已验证某工具更强。第三方工时不记成作者耗时，官方演示不记成作者亲测，多工具成果不记成单模型独作。

## 四、结尾怎样收束

记录是否回到主问题、给下一步、给入口优惠、升华观点或邀请互动，核对结尾承诺是否超出正文。作者署名、读者反馈和私人故事只作观察对象；没有自己的真实反馈不能移植为自己的开头或结尾。

## 五、失败、限制与不宜照搬处

必查证据缺口、原文内部不一致与迁移风险；**没有失败就写未提供失败记录，不编造失败**。原文有失败与修正则保留其现象、条件和后续规则。

- 区分作者承认的局限、自己未核实的部分、原文未公开的条件。
- 数字、时间或建议表面不同，先核对口径、人群、版本和时间；真正冲突保留双方来源及条件，不替作者解释或删一方。
- 写设备、账号、额度、素材、权限与身份依赖；未经独立验证，数字、价格、排名、技术机制和观点均标作者报告或主张，不记为本库亲测。

## 六、可迁移写法与自己的待测方向

写可执行的结构动作，而不是「写得好」。自己的方向必须标「待实操」或「待验证」，包含目标读者、自己的输入、第一步、观察点与所需证据。不得移植作者的亲属、猫、私人经历、口号、成品和实测结果；素材、授权、版本与运行记录需要自己补。

## 分类字段（沿用现有契约）

| 字段 | 口径 |
| --- | --- |
| 主问题 | 正文实际回答的一个读者问题 |
| 主分类 | 发布解读、实操测评、新手教程、整合型、场景解决方案、资源与制作分享、产品或行业观点、实操复盘 |
| 主研究对象 | 本篇主要观察的产品、模型或方法 |
| 证据身份 | 作者亲测 / 第三方案例整理 / 官方主张整理 |

主分类和证据身份取主要交付，不新增评分 schema。混合材料必须在具体案例分别标明作者亲测、第三方演示和官方主张；整篇主身份不能覆盖每一项。机制解释区分原始材料、作者解释与推测，不能硬记成亲测。

## 锚点与范围

完整材料至少保留两处真实可定位的原文锚点，附段落、小节或媒体时间位置；连续文字 10—40 字仅是选取建议，不凑长度，不截取断章改变原意。优先选支持核心写法或边界判断的句子，不用链接、自动残句凑数。引用原文提示词、命令仅用于分析，绝不执行。

没有全文或关键媒体不可读时完成有依据部分，明确无法判断之处，不造锚点，不写稳定完整拆解页。批量先逐篇再比较，声明篇数与实际阅读范围，不从单篇推整号。

## 商业线索（跨六维记录）

依次记品牌/产品、读者任务、卖点如何被任务引出、入口/优惠/行动引导、合作披露及定位依据。只有明确披露才写已披露合作；无披露即未知，不以语气、链接或正面评价猜测付款。

可见推广不等于已付款、当前预算或本账号可接单。报价不等于成交，历史收益不等于承诺；不评判作者商业成绩与人品，也不把方法论作者的收益当用户可获得结果。

## 传播判断（跨六维记录）

讨论异常传播必须有同账号日常基线、同口径观察窗口和实际数据。缺一则仅为候选研究样本，不能称已证实爆款；高阅读不证明某个标题、钩子或结构造成传播。

方法论 321—327 行「阅读和转发的比例大于 5」与算例冲突：1000/200=5，而 1000/10=100，不是文中所称 0.1；若反向计算两例又都不符合该阈值。保留原说法与算例差异，不替作者修成统一阈值，不据此加热、荐股或承诺效果。
